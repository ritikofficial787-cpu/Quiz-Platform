## 📌 About the Project

**QuizLearn** is a student-focused quiz website built using ASP.NET Web Forms and C#. The goal of the project is to provide a simple and user-friendly platform where students can access quizzes, practice questions, review mistakes, and view their results.

The website focuses on a clean interface, straightforward navigation, and a smooth learning experience.

## ✨ Features

- 🔐 **Login and Registration** — User authentication interface for students.
- 👤 **Profile Setup** — A personal information step for new users.
- 📊 **Student Dashboard** — A central place to access learning features.
- 🧠 **Interactive Quizzes** — A quiz experience for practicing questions.
- 📚 **Subject Selection** — Choose a subject before starting a quiz, where supported.
- 🏆 **Quiz Results** — View quiz performance and results.
- 📝 **Review Mistakes** — Revisit incorrect answers and learn from mistakes.
- 🔔 **Notifications Interface** — A dedicated place for notifications.
- 🎨 **Modern UI** — A clean dark-themed interface with subtle purple accents.
- 📱 **Responsive Layout** — Designed with usability across screen sizes in mind.

*Note: Available functionality depends on the current implementation of the project.*

## 🖥️ Website Working Flow

  <img src="https://readme-typing-svg.demolab.com?font=Fira+Code&size=20&pause=1200&color=A78BFA&center=true&vCenter=true&width=650&lines=Sign+Up+%E2%86%92+Profile+Setup;Login+%E2%86%92+Student+Dashboard;Choose+Quiz+%E2%86%92+Answer+Questions;View+Results+%E2%86%92+Review+Mistakes" alt="Animated website workflow" />

1. **Get Started:** The user opens the website and proceeds to registration or login.
2. **Create an Account:** A new user completes the signup process.
3. **Profile Setup:** New users can provide personal details through the profile setup screen.
4. **Login:** Returning users sign in to access their dashboard.
5. **Student Dashboard:** Students navigate to the available learning features.
6. **Start a Quiz:** The student selects a subject and starts a quiz, where available.
7. **View Results:** After completing a quiz, the student can review their performance.
8. **Review Mistakes:** Students can revisit incorrect answers to support learning.

## 🚀 Getting Started

Follow these steps to run the project locally.

### Prerequisites

- Windows
- Visual Studio 2022 or a compatible version
- ASP.NET and .NET Framework development components
- The .NET Framework version required by the project

### Installation

**1. Clone the repository**

```bash
git clone https://github.com/ritikofficial787-cpu/Quiz-Website.git
```

**2. Open the project**

Open the downloaded project or its solution file (`.sln`) in Visual Studio.

If the repository does not contain a solution file, open the existing ASP.NET Web Forms project using the appropriate Visual Studio workflow.

**3. Restore dependencies**

Allow Visual Studio to restore any required NuGet packages.

**4. Configure the application**

Check the existing `Web.config` and project settings. Configure any required local dependencies before running the website.

**5. Run the website**

Press `F5` in Visual Studio to run with debugging, or use `Ctrl + F5` to run without debugging.

The website will open in your default browser if the project is configured correctly.
