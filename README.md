# Quiz-Platform

This repository contains the Quiz-Platform ASP.NET Web Forms project.

How to publish
1. Create a new repository on GitHub named `Quiz-Platform`.
2. Add the remote and push from your local machine:

   git remote add origin https://github.com/<your-username>/Quiz-Platform.git
   git push -u origin master

Notes
- A .gitignore is included to exclude build artifacts and user-specific files. If any unwanted files are already tracked, run:

  git rm -r --cached .
  git add .
  git commit -m "Remove ignored files"

If you want me to set the remote and push, provide your GitHub repo URL or username and confirm.
